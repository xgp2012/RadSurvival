# RadSurvival

> 白天的阳光会杀死你。找阴影，穿盔甲，活得久一点。

Minecraft **Paper 1.21.11** 的辐射生存插件。太阳成了敌人，暴露在露天就会持续受到辐射伤害；
晒得越久「腐蚀值」越高，伤害也跟着越来越猛。想活下去只有两条路——**躲进遮蔽**，或者**穿够盔甲**。

---

## 一秒看懂

- ☀️ **白天露天 = 持续掉血**，夜晚伤害减半
- 🌫️ **阴影就是安全区**——进洞、进屋、站到方块底下立刻停止受伤
- 💀 **腐蚀条会说谎**——它涨的是伤害倍率，不是血量
- 🛡️ **盔甲只能减伤，不能免伤**——连下界合金全套也照样被晒死
- 🧪 **抗尘埃药才是唯一真免疫**——发射器+铁砧+一圈原木就能自己做
- 📊 **屏幕底部常驻状态条**，一眼看出当前危险程度

## 快速开始

### 1. 下载

**[→ 下载最新版本](https://github.com/xgp2012/RadSurvival/releases/latest)**

拿到一个 `RadSurvival-年-月-日-序号.jar` 文件，比如 `RadSurvival-2026-10-25-1.jar`。

### 2. 安装

把 jar 丢进服务器的 `plugins/` 目录，重启服务器。就这样——**不需要联网，不需要额外插件**。

### 3. 确认能用

服务器起来后，控制台会出现四行摘要：

```
[RadSurvival] 抗尘埃药 · 4 个档位（refined/strong/improved/crude）· 冷却 20s · 结构 = 发射器 + 上方铁砧 + 一圈原木，木棍右键铁砧出品
[RadSurvival] 已启用 · tick=20 base=1 night×0.5 worlds=[world] dim=[NORMAL] 腐蚀=on max×2 async=on armor≤72%
[RadSurvival] 反馈层 · HUD=actionbar 粒子=WHITE_SMOKE 音效=on 死亡文案=on 红闪抑制=off
[RadSurvival] 接线 · 监听器 7 个（会话/标记/伤害门控/反馈/死亡文案/抗尘埃药），在线玩家 0 名已预填
```

> 把 `anti_dust.enabled` 设为 `false` 后，第一行消失、监听器数量变成 5 个，发射器完全退回原版行为。

进游戏后执行 `/rad status`，能出一份当前判定报告就算装好了。

### 4. 需要改设置？

打开 `plugins/RadSurvival/config.yml`，改完执行 `/rad reload`。

> 怕改坏？先跑 `/rad reload --dry-run`——它只检查配置合不合法，**不会真的应用**。
> 就算配置写错了，插件也会保留旧配置继续跑，不会把服务器搞挂。

## 玩法说明

### 阳光下的规则

白天站在露天，每 20 tick（1 秒）掉一次血。默认每秒 **1 点（半颗心）**——满血能撑 20 秒左右，
但这只是开始，腐蚀会不断加重它。

**夜晚**伤害减半。黎明和黄昏会平滑过渡，不会突然跳变。

### 腐蚀条：真正的威胁

屏幕下方有两根条。左边是**辐射等级**（当前这一秒会掉多少血），右边是**腐蚀条**。

腐蚀是这样运作的：

| 你做的事 | 腐蚀值 |
|---|---|
| 露天待着（白天） | 每秒 +1% |
| 躲在阴影里 | 每秒 −1% |
| 下界 / 末地 | 只降不升（那边没有太阳） |
| 掉线 | 冻结（不涨也不掉） |
| 死亡 | 清零（默认） |

腐蚀越高，伤害倍率越高。**腐蚀 100% 时伤害翻倍**（默认 ×2 封顶）。
也就是说，同样站在太阳底下，刚出门的你和晒了一分半钟的你，掉血速度完全不一样。

### 屏幕上的提示

状态条会直接告诉你当前处境：

| 显示 | 意味着 |
|---|---|
| `▲▲▲▲▲` | 露天满强度，正在快速掉血 |
| `▲▲△△△` | 露天但强度较低（夜晚或晨昏） |
| `●安全` | 你有遮蔽，安全 |
| `◆抗尘` | 你刚喝了抗尘埃药，短时间内完全免疫 |
| `腐蚀 67% ▓▓▓▓▓▓▓░░` | 腐蚀值，颜色变黄变红代表快到危险区间 |

腐蚀到 50% 和 75% 时会有明显的标题提示和音效——那是在提醒你**该找地方躲了**。

### 盔甲怎么算

四件盔甲各自贡献一部分减免，材质越好效果越强。**但再好的盔甲也挡不住全部伤害**：

| 材质 | 全套满配减免 | 还能打进来的伤害 |
|---|---|---|
| 皮革 | 15% | 85% |
| 金 / 锁链 | 30% | 70% |
| 铁 | 48% | 52% |
| 钻石 | 60% | 40% |
| 下界合金 | 72% | 28% |

> **重要**：早期版本里「全套下界合金 = 完全免疫」的设定已经移除。现在穿满下界合金
> 依然会被太阳晒死（大约 56 秒），只是死得慢一些。想要真正的免疫，只能靠**抗尘埃药**。

另外还有一道兜底：**任何减免都不可能把伤害压到零**。即使服主把系数调到接近免疫，
每一轮的伤害也不会低于基准的 10%——护甲是减伤，不是免伤。
（默认数值下这层兜底还碰不到，因为最高减免 72% 离 90% 还远；它是防止「改配置改出免疫」的保险。）

**穿满 ≠ 安全**：减免是按部位加权的（胸甲权重最高，靴子最低）。缺一件就漏一块。
具体数值见 [完整配置参考](ADVANCED.md#32-armor-盔甲减免)。

### 抗尘埃药：唯一能真正免疫的办法

抗尘埃药喝下去会**立刻降低一截腐蚀值**，并在一段时间内**完全免疫辐射**。腐蚀越高越值得喝。

药有四个档位，用不同的农作物做，效果也不同：

| 档位 | 降低腐蚀 | 免疫时长 | 用这些作物做 |
|---|---|---|---|
| 精制抗尘埃药 | −50% | 30 秒 | 金胡萝卜、紫颂果、发光浆果、附魔金苹果 |
| 强效抗尘埃药 | −35% | 20 秒 | 下界疣、绯红菌、诡异菌、甜浆果 |
| 改良抗尘埃药 | −25% | 15 秒 | 南瓜、西瓜片、甘蔗、可可豆、红/棕色蘑菇 |
| 粗制抗尘埃药 | −15% | 10 秒 | 小麦、胡萝卜、土豆、甜菜根、海带、干海带、竹子、仙人掌 |

喝药还会顺手清掉中毒、饥饿、反胃、虚弱、缓慢这类负面状态。

**怎么搭这个「制药台」**（注意：不是工作台，也不是合成表）：

1. 在平地上放一台 **发射器**（投掷器也行）
2. 在它**正上方那一格**压一个 **铁砧**（损坏的、上蜡的都行）
3. 在它**同一层的 8 个周围格子**各放一个 **原木**（什么树都行，可以混着放）
4. **右键发射器**，把农作物放进界面**正中间**那一格
5. 手持 **木棍**，**右键铁砧**——药就出来了

```
       橡木   铁砧   橡木
       橡木  发射器  橡木     ← 发射器的界面就是放作物的地方
       橡木   橡木   橡木
```

- 木棍只是「钥匙」，**不会被消耗**
- 一次消耗 1 个作物，产 1 瓶药
- 两次喝药之间默认有 **20 秒冷却**
- 界面外围那 8 格只是摆放示意：**放不进去**（点击会被拦下并提示「作物请放正中间」），
  但已经放在里面的东西随时能拿回来
- 中心格只收农作物；放别的会被拦下并提示「不能用来制作抗尘埃药」

### 躲在哪里算安全

- ✅ 山洞、房子、树下、方块底下、玻璃顶棚
- ❌ 只是站在高处但头顶是开阔天空
- ❌ 跳进水里（水不算遮蔽）

创造模式和旁观模式**完全免疫**，冒险模式默认参与结算。

## 命令

玩家自己能用的：

| 命令 | 作用 |
|---|---|
| `/rad status` | 看自己现在会不会掉血、为什么 |
| `/rad force-check` | 立刻结算一次，看实际掉多少血 |

管理员用的：

| 命令 | 作用 |
|---|---|
| `/rad reload` | 重载配置 |
| `/rad reload --dry-run` | 只检查配置，不应用 |
| `/rad corrosion get <玩家>` | 查某个玩家的腐蚀值 |
| `/rad corrosion set <玩家> <值>` | 设置腐蚀值（0–100） |
| `/rad corrosion add <玩家> <值>` | 增减腐蚀值（可以填负数） |
| `/rad dust list` | 列出抗尘埃药的四个档位和对应作物 |
| `/rad dust give <档位> [玩家]` | 直接发一瓶药（调试/活动用） |
| `/rad dust help` | 查看制药台怎么搭 |

完整的别名、权限节点见 [命令与权限全表](ADVANCED.md#4-命令与权限全表)。

## 权限

| 节点 | 默认 | 作用 |
|---|---|---|
| `radsurvival.use` | 所有人 | 使用 `/rad status`、`/rad force-check` |
| `radsurvival.exempt` | 无 | **完全豁免辐射**（不掉血也不累积腐蚀） |
| `radsurvival.admin` | OP | 腐蚀条管理命令 |
| `radsurvival.reload` | OP | `/rad reload` |

想让某个玩家或某个世界不受影响？

- 单个玩家 → 给 `radsurvival.exempt` 权限
- 整个世界 → 改 `config.yml` 里的 `enabled-worlds`

## 常见问题

**装了但玩家不掉血？**
执行 `/rad status` 看报告里的跳过原因。最常见的是：玩家在创造模式、所在世界不在
`enabled-worlds` 里、或者正好站在遮蔽物下面。

**腐蚀在涨但血不掉？**
说明 `tick-interval` 被改到了 20 以下。原版受击后有 20 tick 无敌帧，间隔太短伤害会被吞掉。
改回 20 或更大即可。

**设了制药台但敲铁砧没反应？**
按 `/rad dust help` 对照检查：铁砧必须在发射器**正上方那一格**，8 个周围格子必须都是**原木**
（木板、台阶不行），发射器**正中间**那一格必须放着农作物。三条缺一条都不会产出，但不会扣你的东西。

**抗尘埃药喝了没效果？**
如果显示「冷却中」，等 20 秒（`anti_dust.cooldown-seconds`）。如果显示「配方已失效」，
说明服主改了配置删掉了那一档——找服主换一瓶，或者用 `/rad dust list` 看现存的档位。

**下界和末地也会掉血？**
检查 `dimensions` 配置。默认只有 `NORMAL`（主世界），下界/末地是豁免的。

**玻璃顶不算安全？**
`transparent-blocks-count-as-cover` 默认是 `true`（玻璃算遮蔽）。如果被改成了 `false` 就不算。

**日志里中文是乱码？**
Windows 控制台是 GBK 编码，插件输出 UTF-8。这只影响控制台显示，游戏内和 RCON 完全正常。
启动时加 `-Dstdout.encoding=UTF-8` 或者先执行 `chcp 65001` 即可。

**能和其他插件一起用吗？**
可以。ProtocolLib 和 PlaceholderAPI 是可选增强——装了会启用红闪抑制和 `%radsurvival_*%`
占位符，不装也完全不影响核心玩法。

更多排错见 [已知限制与排错](ADVANCED.md#12-已知限制与排错)。

## 技术信息

| 项 | 值 |
|---|---|
| 平台 | Paper 1.21.11（`api-version: 1.21`） |
| Java | 21+ |
| 依赖 | 无（ProtocolLib / PlaceholderAPI 可选） |
| 大小 | 约 1.8 MB（自包含，内嵌库已重定位） |
| NMS | 不使用 |
| 测试 | 265 条自动化测试 |

每次推送到主分支都会自动构建并跑完整测试，发布前还有门禁——测试数量异常会直接中止发布，
避免坏包流出去。构建产物命名格式是 `RadSurvival-<年>-<月>-<日>-<当天第几次构建>.jar`，
每次发布附带 `.sha256` 校验文件，细节见 [下载与自动发行](ADVANCED.md#1-下载与自动发行)。
